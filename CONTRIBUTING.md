# Contributing

Thanks for helping improve the agent swarm.

## Before you open a pull request

- Read `AGENTS.md` and the relevant files under `swarm/`.
- Keep private infrastructure details, credentials, personal names, and
  machine-specific paths out of tracked files. Use the documented placeholders.
- Run `cd swarm && npm test` and include any relevant security-scan output.
- Keep changes focused and explain the operational impact in the pull request.

## DCO and licensing

By contributing, you certify the [Developer Certificate of Origin](https://developercertificate.org/)
by signing each commit with a `Signed-off-by:` trailer (for example,
`git commit -s`). This confirms that you have the right to submit the work.

You also agree that your contribution may be distributed under this repository's
PolyForm Shield 1.0.0 license, including its prohibition on competing products.
This lets the project owner ship the combined work under the same terms.
